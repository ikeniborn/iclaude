Резюме спецификации

Источник: docs/superpowers/specs/2026-07-01-iwiki-mcp-user-scope-design.md · spec_hash ff63ddc066677423

Цель: зарегистрировать MCP-сервер iwiki версионируемо и без захардкоженных секретов, вытягивая все IWIKI_* из единого источника .claude_config (префикс ICLAUDE_IWIKI_*). Бинарь резолвится в абсолютный путь на запуске.

РазделТребование
R1 · Component 1Создать secret-free файл .nvm-isolated/.claude-isolated/mcp/iwiki.json в формате .mcp.json; сервер iwiki (stdio), только плейсхолдеры ${…}, ноль секретов → безопасно версионировать.
R2 · Component 1Передать 11 IWIKI_* переменных, что читает сервер: required (LLM_BASE_URL, LLM_KEY, BASE_DIR) плейн ${VAR}; optional (EMBED_MODEL, EMBED_DIMENSIONS, CHUNK_SIZE, CHUNK_OVERLAP, SUMMARY_MAX_CHARS, TOP_K, SCORE_THRESHOLD, GRAPH_DEPTH) через ${VAR:-<дефолт>}. IWIKI_PROJECT_DIR опущен (cwd = проект).
R3 · Component 2Резолв бинаря на запуске: IWIKI_COMMAND="${IWIKI_COMMAND:-$(command -v iwiki-mcp)}"; абсолютный путь из PATH, портативно между ПК; опциональный override ICLAUDE_IWIKI_COMMAND. Пусто → сервер не регистрируется.
R4 · Component 3В native-пути после сборки claude_cmd_arr условно добавить --mcp-config <abs>/mcp/iwiki.json (гард: IWIKI_COMMAND непусто И IWIKI_LLM_KEY непусто И файл есть). Флаг попадает в обе ветки (PII-proxy и exec). microVM-путь исключён.
R5 · Component 4Добавить ICLAUDE_IWIKI_BASE_DIR в .claude_config и .claude_config.example; env-map де-префиксит → экспортит IWIKI_BASE_DIR. Опциональный ICLAUDE_IWIKI_COMMAND.
R6 · Component 5Удалить ручной блок mcpServers.iwiki из .claude.json (файл оставить, Claude им владеет); удалить мёртвый "mcpServers": {} из settings.json.
R7 · Component 6Снять новый файл из-под бланкет-игнора .claude-isolated/* (!.../mcp/ + !.../mcp/**).

SC5git status — mcp/iwiki.json tracked, .claude.json остаётся ignored.
