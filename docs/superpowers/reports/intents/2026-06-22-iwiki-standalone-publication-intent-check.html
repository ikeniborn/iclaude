1. Резюме требований

Objective

Отделить плагин iwiki от репозитория iclaude и опубликовать его автономно в официальном маркетплейсе Anthropic claude-code. Два равнозначных драйвера: (1) sharing — другие проекты могут устанавливать iwiki прямо из официального маркетплейса; (2) decoupling — iclaude перестаёт включать исходники плагина в сборку и переходит на внешнюю зависимость.

Desired Outcomes

#Outcome
DO-1Автономный репозиторий iwiki (отдельный от iclaude) собирает и прогоняет engine-тесты pytest зелёно в собственном CI.
DO-2В чистом проекте без iclaude команды plugin marketplace add <repo> + plugin install работают end-to-end: engine самостоятельно поднимает uv, и навыки/команды /iwiki-* функционируют.
DO-3Плагин принят в официальном маркетплейсе Anthropic (PR submittted/merged; листинг активен). Внешний фактор — зависит от мейнтейнеров; см. Stop Rules.
DO-4iclaude больше не включает исходники iwiki в сборку; он потребляет опубликованный плагин из маркетплейса. WARNING F-003

Health Metrics

#Метрика
HM-1iwiki продолжает работать внутри iclaude точно так же, как раньше (docs/wiki/, /iwiki-*, четыре автоматических хука) — без регрессий в ходе и после перехода. WARNING F-001
HM-2Engine-тесты pytest Phase-B (27 тестов) остаются зелёными в новом репозитории/CI.
HM-3Поведение engine и хуков идентично: search/index/lint/related и хуки recall/sync/reindex/bootstrap работают ровно как сегодня (нет drift от decoupling).
HM-4Существующие установки iwiki@iclaude продолжают работать, или существует явный задокументированный migration path. WARNING F-002

Constraints

#ТипОграничение
S1SteeringСледовать официальным конвенциям маркетплейса Anthropic (manifest schema, README/LICENSE layout, contributor/disclosure).
S2SteeringДемо/пример в standalone-репозитории — generic, не iclaude-специфичный.
S3SteeringDecoupling хирургически: перемещать/упаковывать, не переписывать. Минимальные изменения для самодостаточного плагина.
H1HardНулевая зависимость от iclaude. Плагин работает без кода iclaude (lib/, .claude_config); всё через переменные окружения.
H2HardПоведение engine без изменений. Decoupling — только упаковка, без изменений логики engine/хуков.
H3HardRuntime остаётся httpx-only. Никаких новых runtime-зависимостей; pytest — только dev.
H4HardMIT-лицензия сохраняется; правила маркетплейса Anthropic соблюдены (manifest, структура, disclosure).

Autonomy Zones

ЗонаДействия
FullЧерновики файлов standalone-репозитория на ветке/worktree: README, LICENSE, manifest маркетплейса, CI-конфиг, CHANGELOG, packaging scaffolding.
Guarded (log + verify)Реализация самодостаточного uv-bootstrap внутри плагина и packaging, делающий его устанавливаемым без iclaude; каждый шаг верифицируется по health metrics (поведение engine + 27 тестов).
Proposal-firstРешение по структуре/стратегии репозитория (новый репо vs split-with-history, migration path) и удаление bundled iwiki из iclaude для перехода на внешнее потребление.
No autonomy (human only)Создание публичного GitHub-репозитория, любой PR/submission в официальный маркетплейс Anthropic (push-to-public + необратимый листинг + disclosure).
Stop Rules (развернуть)
  • Halt if: шаг decoupling изменяет поведение engine/хуков, добавляет runtime-зависимость, или ломает собственный iwiki iclaude.
  • Escalate if: достигается внешнее или структурное действие — создание публичного репо, сабмит в маркетплейс, удаление iclaude-bundle, выбор структуры репозитория.
  • Done when (все условия):
    • CI standalone-репозитория: engine pytest suite зелёный
    • Установка в чистом проекте (без iclaude): /iwiki-* работают через self-bootstrapped uv
    • Submission в официальный маркетплейс открыт
    • iclaude потребляет внешний плагин без bundled-исходников
    • Собственный iwiki iclaude + 27 тестов по-прежнему проходят
