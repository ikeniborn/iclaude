4. Влияние на систему

КомпонентИзменение поведенияРиск / что дальше
Правила агента
CLAUDE.md		 Каждая задача — включая direct и read-only — открывает страницу в вики до первого изменения. События пишутся сразу, без буфера Охват шире прежнего: раньше строку получали только chain и LoEn. Нагрузка на MCP выросла

История задач 14 закрытых строк — в архивной странице, полный текст Notes обрезан до 120 символов по границе слова Несокращённый оригинал: git show e91aedde:docs/TODO.md, ссылка указана в лиде Evidence
Открытые следствия. Task-страницы всегда числятся orphan в wiki_lint — отказ от центрального индекса лишает их входящих ссылок; критерий завершения поэтому звучит как «нет новых находок по task-странице», а не «чистый lint». Идемпотентные ключи вычисляет модель, кода за ними нет — дедупликация при replay остаётся best-effort. Поведение spool под реальный отказ не проверено: тестов нет, только правило.
