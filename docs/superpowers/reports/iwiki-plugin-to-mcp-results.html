РазделТребование
Decisions #1Двухчастный объём: миграция инструкций и decommission-очистка.
Decisions #2Детекция через wiki_status (MCP-native) вместо гейта exists docs/wiki/; путь docs/wiki/ убирается как концепт повсеместно.
Decisions #3Полный редизайн интеграционных секций вокруг доменной модели MCP (wiki_status → wiki_bind → типизированные вызовы), не 1:1 замена токенов.
Decisions #4Cross-domain поиск опционален; по умолчанию — связанный домен проекта. wiki_search(domains/scope) — opt-in note.
Decisions #5Сохранить только папку plugin/iwiki/; удалить остальную in-repo интеграцию.
Decisions #6Отключить плагин: settings.json iwiki@iclaude → false; папка остаётся как dormant-архив.
MCP vocabularyКанонический mapping plugin→MCP для всех операций (detect/bind, search, related, read, write, reindex, health, list, new domain).
Detection/bind flowКанонический поток wiki_status → wiki_bind(read,write); домен отсутствует → «не настроен», skip silently.
Write flowМодель сама авторит markdown → wiki_write_page(domain, slug, markdown, source); шаг авторинга делается явным.
Write-flow indexing (resolved)wiki_write_page НЕ авто-индексирует — явный wiki_index(domain) следует за каждой записью (author → write → index); подтвердить на live MCP во время реализации.
§1.1CLAUDE.md (global): «Getting Started» и «Keep Docs Current» — заменить docs/wiki/-гейт и /iwiki-* на MCP-поток + каталог MCP-инструментов.
§1.2context-awareness/SKILL.md: §5 Detection на wiki_status; поля wiki_domain (new), drop wiki_index_path; frontmatter description; delegates; changelog.
§1.3intent/SKILL.md: Step 0 гейт → wiki_status; query → wiki_search; «Context from iwiki domain».
§1.4–1.6agent-builder, prd-generator, prompt-verifier: gate→Query→Record на MCP (wiki_status/wiki_search/wiki_write_page).
§2.1Install machinery: удалить lib/iwiki/, блок Phase 8.0.1 и --install-iwiki в iclaude.sh, help-строку usage.sh, вызов iwiki_export_engine_dir в env-map.sh, обновить комментарий init.sh (uv bootstrap остаётся).
§2.2Config: удалить iwiki-блок в .claude_config.example; сохранить .iwikiignore (читается MCP-сервером для scope ingest/index — не часть удаляемой plugin-машинерии).
§2.3Wiki data: удалить docs/wiki/ (контент + .iwiki/ индекс).
§2.4Tests: удалить 4 файла tests/test_iwiki_* (entrypoint, hook_failopen, hooks, lint).
§2.5Plugin disable: settings.json iwiki@iclaude → false; убрать осиротевшие iwiki hook-записи.
§2.6README: переписать iwiki-секции на MCP-модель; убрать --install-iwiki, /iwiki-*, docs/wiki/.
