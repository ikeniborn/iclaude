Требования (по секциям)

СекцияТребование
§ProblemЗаменить mtime-детекцию устаревания на content-addressed (хеш содержимого источника); устранить ложные «stale» при git reset/checkout, правках в тот же день и копировании файлов.
§What portsПортировать только класс 1 (content-hash freshness). НЕ портировать класс 2 (de-specialization: путь движка plugin/iwiki/engine→engine, удаление .claude_config/detect.sh/iclaude-ссылок, sample в test_chunk). НЕ портировать класс 3 (distribution metadata: version bump plugin.json, marketplace.json).
§Log recordЗаписи ingest/init в docs/wiki/.iwiki/log.jsonl получают опциональный ключ src_hash = sha256(raw bytes).hexdigest()[:16]. Старые записи без ключа работают через mtime. Без миграции/бэкфилла.
§Freshness predicateИнвариант _fresh(src,page,src_hash): если src_hash задан И источник читаем → сравнение по хешу; иначе mtime (page≥source). Хелпер _src_hash возвращает None при OSError. Два call-site (lint._stale и iwiki_common.covered_sources) — точные зеркала: _stale = not _fresh, covered = _fresh.
§Backward/forward compatСтарые записи → mtime (идентично текущему). Нечитаемый источник при заданном src_hash → None → mtime fallback. Никогда не падает (fail-soft).
§Files changedГибридный подход. copy wholesale: lint.py, test_lint.py (+hashlib, +4 теста), test_iwiki_common.py (+hashlib, +2 теста). surgical edit: hooks/iwiki_common.py (add _src_hash/_fresh/_ingest_records, рефактор source_page_map+covered_sources, СОХРАНИТЬ docstring и кандидат plugin/iwiki/engine), iwiki-ingest/SKILL.md и iwiki-init/SKILL.md (step-5 пишет src_hash через sha256sum|cut -c1-16, СОХРАНИТЬ ENG=plugin/iwiki/engine fallback).
§Explicitly NOT touchedconfig.py, test_chunk.py, docstring+_engine_project пути, skills engine-path fallbacks, plugin.json, marketplace.json, README.md.
§Verification1) pytest зелёный, включая 6 новых тестов. 2) grep plugin/iwiki/engine в hook+skills — class-2 пути не регрессировали. 3) grep -rn src_hash plugin/iwiki — фича приземлилась в lint, hook, обоих скиллах.
§Behavioural checkshash match + page mtime OLDER → fresh/covered; hash mismatch + page mtime NEWER → stale/not covered; нет src_hash → mtime behaviour; src_hash есть, но источник нечитаем → mtime fallback.
§Out of scopelib/iwiki (detect.sh/install.sh), любые изменения вне plugin/iwiki, version bump и marketplace metadata.
§Workflow noteБаза ветки (dev vs master), PR target, wk-dev-* worktree — решения пользователя на kickoff, не предполагаются.
