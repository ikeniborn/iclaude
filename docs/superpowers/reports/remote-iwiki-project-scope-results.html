Под удалённым (Streamable HTTP) iwiki MCP-сервером агент теперь обязан применить scope текущего проекта из .iwiki.toml через wiki_bind до любого task-specific wiki-вызова. Реализовано новым SessionStart-хуком, который эмитит managed-инструкцию в additionalContext только при заданном IWIKI_REMOTE_URL; при stdio регион отсутствует автоматически.
