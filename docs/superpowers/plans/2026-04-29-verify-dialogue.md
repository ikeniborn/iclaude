  После шага 4 («Проверь результат») добавить:

  ```markdown

     - Составь нумерованный список всех пунктов из «Требует решения»
     - Для каждого WARNING #N (по порядку):
       - Если он уже помечен `[DECLINED]` в текущей сессии — пропустить

       - `n` → пометить `[DECLINED]`, перейти к WARNING #N+1
     - После обхода всех WARNING → вывести финальный отчёт
  ```

  В блок «Запрещено» добавить строку:

### Task 2: Обновить формат вывода — раздел «Отклонено»

**Files:**
- Modify: `.nvm-isolated/.claude-isolated/commands/verify.md`

- [ ] **Шаг 1: Найти раздел `## Формат вывода`**

  В файле найти блок с шаблоном отчёта (строки с `### Исправлено`, `### Требует решения`, `### Чисто`).

- [ ] **Шаг 2: Добавить раздел `### Отклонено: Z` в шаблон**

  После блока `### Требует решения: Y` и перед `### Чисто: Z файлов` вставить:

  ```markdown
  ### Отклонено: Z
  - [DECLINED] file.sh:65 — описание (отказ пользователя в этой сессии)
  ```

  Итоговый шаблон должен выглядеть так:

  ```
  ## Ревью [дата]

  ### Scope
  - git diff: N файлов / указан путь: <path>

  ### Исправлено: X
  - [CRITICAL] file.py:42 — описание → что сделано

  ### Требует решения: Y
  - [WARNING] file.sh:65 — описание (почему не исправлено автоматически)

  ### Отклонено: Z
  - [DECLINED] file.sh:65 — описание (отказ пользователя в этой сессии)

  ### Чисто: N файлов
  ```

- [ ] **Шаг 3: Добавить пояснение под шаблоном**
