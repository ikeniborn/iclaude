# Result-only HTML report Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop generating the IDD→SDD chain HTML report at the intent/spec/plan stages and produce a single implementation-focused report only at the result stage, retiring the `html-report` `mode: chain` machinery.

**Architecture:** Pure markdown-skill + wiki edits. No Python/hook/settings changes — the `chain-gate.py` hook talks only through artifact frontmatter.

**Tech Stack:** Markdown skill files under `.nvm-isolated/.claude-isolated/skills/`, the `check-chain` and `html-report` skills, the `iclaude` iwiki domain (MCP tools). Verification is `grep`/`test`/file reads plus a dogfood `/check-chain result` run — there is no unit-test framework for skills.

## Global Constraints

- All report body text the `check-chain` result Step 5 emits is **Russian**; skill/reference/doc prose and commit messages are **English**.
- Report output path is unchanged: `docs/superpowers/reports/<topic>-results.html`.
- The new report is generated by `html-report` in its **default `standalone` mode** (never `mode: chain`).
- Do NOT touch phase checklists, severities, the hashing algorithm, `chain-gate.py`, or `settings.json`.
- Do NOT migrate existing four-tab `<topic>-results.html` files on disk.
- Skill root shorthand `skills/…` in this plan means the real path `/home/ikeniborn/Documents/Project/iclaude/.nvm-isolated/.claude-isolated/skills/…`.
- Sections 1–4 of the result report are always present; section 5 (diagrams) only when the structural-change trigger fires.
