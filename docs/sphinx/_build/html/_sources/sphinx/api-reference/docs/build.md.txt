## `build_sphinx_docs`

Build Sphinx documentation for a project Generates API reference from lib/*.sh (bash projects), then builds HTML site

**Arguments:**

- `  $1 - project path (default: pwd)`
- `  $2 - clean build flag (--clean, optional)`

**Returns:**

-   0 - Success
-   1 - Sphinx not installed, not initialized, or build failed

**Example:**

```bash
build_sphinx_docs /path/to/project --clean
```
