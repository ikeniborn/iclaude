# git

> **Module:** `proxy` | **File:** `lib/proxy/git.sh`

Git Proxy Management Module
Description: Backup and restore git proxy settings

---

## `save_git_proxy_settings`

Save current git proxy settings to backup file Side effects:   - Creates GIT_BACKUP_FILE with chmod 600   - Saves current http.proxy and https.proxy from git config

## `restore_git_proxy`

Restore git proxy settings from backup Side effects:   - Restores git config --global http.proxy and https.proxy   - Removes GIT_BACKUP_FILE after restore
