# install

PII-Proxy installation module
Provides function for installing Presidio NLP dependencies

---

## `install_isolated_pii_proxy`

Install PII-proxy to isolated environment Creates venv, installs Presidio + spaCy, copies server script

**Returns:**

-   0 - success
-   1 - error
