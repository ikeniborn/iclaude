# Plans Directory

Этот каталог содержит планы выполнения задач, созданные Claude Code в режиме планирования.

## Конфигурация

Местоположение каталога для планов настроено в `.claude/settings.json`:

```json
{
  "plansDirectory": "docs/plans"
}
```

## Использование

1. **Автоматическое сохранение**: Когда Claude Code входит в режим планирования (plan mode), все планы автоматически сохраняются в этот каталог
2. **Именование**: Планы именуются автоматически по шаблону `plan-<timestamp>.md`
3. **Структура**: Каждый план содержит:
   - Описание задачи
   - Шаги выполнения
   - Зависимости
   - Критические файлы

## Преимущества локального хранения

- ✅ **Версионирование**: Планы хранятся в git вместе с кодом
- ✅ **Видимость**: Легко найти и просмотреть планы в IDE
- ✅ **Совместная работа**: Команда видит планы через git
- ✅ **Документация**: Планы служат историей разработки

## Настройка по умолчанию

Если настройка `plansDirectory` не указана, планы сохраняются в:
- `~/.claude/plans/` (глобальный каталог для всех проектов)

## Примеры

### Создание плана вручную

```bash
# Запустите Claude Code и используйте команду /plan
./iclaude.sh
> /plan Implement user authentication
```

### Просмотр планов

```bash
# Список всех планов
ls -lt docs/plans/

# Просмотр последнего плана
cat docs/plans/plan-*.md | tail -1
```

## Git интеграция

Рекомендуется коммитить планы в git:

```bash
# Добавить план в коммит
git add docs/plans/plan-*.md
git commit -m "docs: add implementation plan for feature X"
```

## Связанные настройки

- `.claude/settings.json` - Конфигурация проекта
- `.claude/settings.local.json` - Локальные настройки (не в git)
- `CLAUDE.md` - Инструкции для Claude Code
