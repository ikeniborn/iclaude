Проблема: Hook не срабатывает
Решение: 
  $ which jq  # Проверить jq установлен
  $ ls -la .nvm-isolated/.claude-isolated/hooks/postToolUse.hook.sh
  $ ./iclaude.sh --install-context-monitor  # Переустановить

Проблема: Уведомления не видны в UI
Решение:
  $ tail -f /tmp/claude-context-monitor.log  # Проверить лог
  $ ./iclaude.sh -- --verbose  # Запустить verbose mode

Проблема: Неправильный подсчет токенов
Решение: Это нормально - обновление после turn (не streaming)
