Обнови граф знаний (по коду) и базу вики (по документации) по итогам доработок. Используется graphify и llm-wiki.

## Разделение ответственности

| Инструмент | Домен | Файлы |
|------------|-------|-------|
| `graphify` | Код, архитектура, зависимости | `*.sh`, `*.py`, `*.js`, `*.ts` и любые не-md изменения |
| `llm-wiki` | Документация, гайды, справочники | `*.md`, `docs/`, `CLAUDE.md`, `README.md` |

## Алгоритм

1. **Определи scope изменений**
   - `git diff HEAD --name-only` → список всех изменённых файлов
   - Если передан путь в `$ARGUMENTS` — работай только с ним
   - Раздели на два списка: **код** (не-md) и **документация** (md + docs/)
   - Если оба списка пусты — сообщи: «Нет изменений. Укажи путь явно или убедись в наличии diff.»

2. **Обнови граф** (если есть изменения кода) — вызови skill `graphify`
   - Scope: изменённые файлы кода
   - Дождись завершения перед следующим шагом

3. **Обнови вики** (если есть изменения документации) — вызови skill `llm-wiki`
   - Scope: изменённые md-файлы и docs/
   - Дождись завершения

4. **Отчёт**

```
## Обновление знаний [дата]

### Scope
- Код (graphify): <список файлов или "нет изменений">
- Документация (llm-wiki): <список файлов или "нет изменений">

### Граф (graphify)
- Статус: обновлён / пропущен (нет изменений кода) / ошибка

### Вики (llm-wiki)
- Статус: обновлена / пропущена (нет изменений документации) / ошибка
- Затронутые домены: <список>
```
