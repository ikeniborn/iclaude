# Example: ingest — Версионирование данных (Ростелеком)

## Сценарий

Пользователь хочет извлечь знания из файла Best Practices по версионированию в хранилище данных Ростелеком.

## Команда

```
/llm-wiki ingest "vaults/Work/Ростелеком/Архитектура модели данных/Best Practices при использовании версионирования.md"
```

---


```markdown
# Версионирование данных (SCD1/SCD2)

Стратегии хранения исторических изменений атрибутов сущностей в хранилище данных Ростелеком (ЦХД).

## Основные характеристики

**SCD1 (перезапись):**
- Старые значения не сохраняются
- Применять для атрибутов, история изменений которых не нужна (технические ключи, справочники без истории)

**SCD2 (хранение истории):**
- Каждое изменение — новая запись с датами актуальности
- Обязательные поля: `дата_начала`, `дата_окончания`, `is_current`
- `дата_окончания = NULL` для текущей записи

## Связанные концепции

- [[clickhouse]] (реализация SCD в ClickHouse)
```

```markdown
# ClickHouse

Колоночная СУБД с открытым исходным кодом, применяемая в Ростелеком как основное хранилище аналитических данных.

## Основные характеристики

Колоночное хранение данных обеспечивает высокую скорость аналитических запросов на больших объёмах.
Используется в потоке GreenPlum → S3 → ClickHouse как целевое хранилище витрин.
```
