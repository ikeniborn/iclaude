# Поток данных GreenPlum → S3 → ClickHouse

Трёхзвенный ETL-поток передачи операционных данных в аналитическое хранилище Ростелеком (ЦХД).

## Основные характеристики

**GreenPlum (источник)**
Операционное хранилище, содержит исторические данные по абонентам, договорам, услугам.
Источник для большинства ETL-процессов ЦХД.

**S3 (промежуточный слой)**
Хранилище сырых выгрузок — буфер и точка восстановления при ошибках загрузки.
Формат хранения: Parquet/CSV.

**ClickHouse (целевое хранилище)**
Колоночная СУБД для аналитических витрин. Загрузка через RT.DataExporter / RT.DataUploader.

## Связанные концепции

- [[версионирование-scd]]
- [[clickhouse]]
