# Критерии операции lint

## Уровни severity

| Уровень | Значение | Требует действия |
|---------|----------|-----------------|
| `error` | Критическая проблема, страница некорректна | Немедленно |
| `warning` | Рекомендуется исправить | В ближайшее время |
| `info` | Информационное замечание | По желанию |

---

## FM — Проверки frontmatter

| ID | Severity | Проверка | Рекомендация |
|----|----------|----------|-------------|
| FM-001 | error | Поле `wiki_sources` отсутствует или пустой массив | Добавить пути к источникам или удалить страницу |
| FM-002 | error | Поле `wiki_updated` отсутствует или не формат YYYY-MM-DD | Установить дату последнего обновления |
| FM-003 | error | Поле `wiki_status` отсутствует или значение вне enum [stub, developing, mature] | Установить корректный статус |
| FM-004 | warning | Поле `tags` отсутствует или пустой массив | Добавить теги из tag-hierarchy.json |
| FM-005 | warning | Путь в `wiki_sources` не существует в файловой системе | Проверить путь или обновить источник |
| FM-006 | info | Поле `aliases` отсутствует для страниц с техническими терминами | Добавить алиасы для удобного поиска |

---

## CT — Проверки контента

| ID | Severity | Проверка | Рекомендация |
|----|----------|----------|-------------|
| CT-001 | error | Страница содержит только frontmatter, нет контента после H1 | Запустить ingest или удалить страницу |
| CT-002 | warning | wiki_status = "stub" и wiki_updated старше 30 дней | Запустить ingest для добавления контента |
| CT-003 | warning | WikiLink `[[ссылка]]` ведёт на несуществующий файл в !Wiki | Удалить ссылку или создать страницу |
| CT-004 | info | Страница не упоминается ни одной другой страницей вики (orphan) | Добавить ссылки из связанных страниц |
| CT-005 | warning | Страница содержит placeholder-текст: "TODO", "см. источник", "будет добавлено" | Заполнить или удалить placeholder |
| CT-006 | info | wiki_status = "developing" и wiki_updated старше 60 дней без новых источников | Проверить актуальность, возможно promote до mature |

---

## ST — Проверки структуры вики

| ID | Severity | Проверка | Рекомендация |
|----|----------|----------|-------------|
| ST-001 | error | `_index.md` содержит ссылку на несуществующий файл | Удалить запись из _index.md |
| ST-002 | warning | Файл `.md` существует в папке !Wiki/, но не упомянут в `_index.md` | Добавить страницу в _index.md |
| ST-003 | info | `_log.md` не обновлялся > 7 дней | Нет активности в вики, возможно требуется ingest |
| ST-004 | warning | Файл вики находится в папке домена, не соответствующей domain-map | Переместить в корректную папку или обновить domain-map |
| ST-005 | error | `_schema.md` отсутствует | Критично: без схемы операции невозможны |
| ST-006 | error | `domain-map.json` недоступен | Критично: без маппинга невозможно определить домены |

---

## CV — Проверки покрытия

| ID | Severity | Проверка | Рекомендация |
|----|----------|----------|-------------|
| CV-001 | info | Файл источника добавлен в vault > 7 дней назад и НЕ упоминается ни в одном `wiki_sources` | Запустить `/llm-wiki ingest {путь}` |
| CV-002 | warning | Домен содержит > 20 файлов источников, но < 5 wiki-страниц | Запустить `/llm-wiki init {домен}` |

## Формат отчёта lint

```markdown
# Lint Report — {section или "Весь Wiki"}

**Дата:** YYYY-MM-DD  
**Проверено страниц:** N  
**Разделов:** [список доменов]

## Итого

| Уровень | Количество |
|---------|-----------|
| Errors | N |
| Warnings | M |
| Info | K |

---

## Errors (требуют исправления)

### [FM-001] Отсутствует wiki_sources

**Файл:** `vaults/Work/!Wiki/базы-данных/субд/aerospike.md`  
**Детали:** Frontmatter не содержит поле wiki_sources  
**Рекомендация:** Добавить wiki_sources с путями к источникам или удалить страницу если источников нет

---

## Warnings

### [CT-002] Stub-страница без обновлений > 30 дней

**Файл:** `vaults/Work/!Wiki/ии/паттерны/rag-паттерн.md`  
**Детали:** wiki_status=stub, wiki_updated=2026-02-10 (63 дня назад)  
**Рекомендация:** Запустить `/llm-wiki ingest` для источников: vaults/Work/ИИ/Explore/LLM/...

---

## Info

### [CT-004] Orphan страница

**Файл:** `vaults/Work/!Wiki/ростелеком/архитектура-данных/биллинг-модель.md`  
**Детали:** Ни одна другая страница вики не ссылается на эту  
**Рекомендация:** Добавить [[биллинг-модель]] в связанные концепции на страницах абонент.md или сущности-цхд.md

---

## Следующие шаги

1. Исправить N errors (критично для корректной работы скилла)
2. Запустить `/llm-wiki ingest` для M файлов без покрытия
3. Обновить K stub-страниц старше 30 дней
```

---

## Алгоритм выполнения lint

### Шаг 1: Загрузка контекста
```
Читать @shared:domain-map
Читать vaults/Work/!Wiki/_schema.md
Читать vaults/Work/!Wiki/_index.md
```

### Шаг 2: Сбор файлов
```
Если section указан:
  Glob "vaults/Work/!Wiki/{section}/**/*.md"
Иначе:
  Glob "vaults/Work/!Wiki/**/*.md"
  Исключить: _index.md, _log.md, _schema.md
```

### Шаг 3: Проверки для каждого файла
Для каждого `.md` файла:
1. Прочитать через Read tool
2. Извлечь frontmatter (YAML между `---`)
3. Выполнить все FM-* проверки
4. Выполнить CT-001, CT-005: проверка контента
5. Собрать все WikiLinks для батч-проверки CT-003

### Шаг 4: Батч-проверки (по всем файлам вместе)
- CT-003: Собрать все WikiLinks → проверить существование файлов
- CT-004: Собрать все исходящие ссылки → вычислить orphan-страницы (нет входящих)
- ST-001, ST-002: Сравнить _index.md с реальными файлами

### Шаг 5: Проверки покрытия (CV-*)
- Glob по source_paths каждого домена
- Сравнить с wiki_sources всех wiki-страниц
- Файлы без упоминаний — кандидаты для CV-001

### Шаг 6: Формирование отчёта
Сгруппировать issues по severity → вывести отчёт по формату выше.
