# Переменные конфигурации прокси

Переменные для настройки прокси задаются в `.claude_config`. Применяются при каждом запуске `iclaude.sh`.

## Справочник переменных

### `PROXY_URL`

Адрес прокси-сервера.

```bash
# Форматы:
PROXY_URL=https://host:port
PROXY_URL=https://[CREDENTIALS]@host:port
PROXY_URL=http://[CREDENTIALS]@host:port
```

| Протокол | Статус | Рекомендация |
|----------|--------|--------------|
| HTTPS | ✅ Полная поддержка | Рекомендуется |
| HTTP | ✅ Полная поддержка | Только для localhost |
| SOCKS5 | ❌ Не поддерживается | Вызывает краш (`InvalidArgumentError`) |

Специальные символы в пароле нужно URL-кодировать: `@` → `%40`, `:` → `%3A`.

---

### `PROXY_CA`

Путь к CA-сертификату прокси-сервера (PEM-формат). Используется при MITM-прокси (корпоративный перехват HTTPS).

```bash
PROXY_CA=/etc/ssl/certs/corporate-ca.pem
```

Если задан — iclaude автоматически выставляет `NODE_EXTRA_CA_CERTS`.

**Предпочтительнее `PROXY_INSECURE=true`** — проверка TLS сохраняется.

Экспортировать сертификат прокси:
```bash
openssl s_client -showcerts -connect proxy:8118 < /dev/null 2>/dev/null | \
  openssl x509 -outform PEM > proxy-cert.pem
```

---

### `PROXY_INSECURE`

Отключает проверку TLS-сертификата прокси.

```bash
PROXY_INSECURE=false   # по умолчанию (рекомендуется)
PROXY_INSECURE=true    # небезопасно — только в крайнем случае
```

**Используйте `PROXY_CA` вместо `PROXY_INSECURE=true`**.

---

### `NO_PROXY`

Список хостов, которые обходят прокси (через запятую).

```bash
NO_PROXY=localhost,127.0.0.1,::1,internal.company.com
```

Значение по умолчанию (если не задан):
`localhost,127.0.0.1,::1,github.com,githubusercontent.com,gitlab.com,bitbucket.org,registry.npmjs.org,nodejs.org`

## Установка через CLI

```bash
# Задать HTTPS прокси (сохраняется в .claude_config)
./iclaude.sh --proxy https://[CREDENTIALS]@proxy:8118

# Добавить CA-сертификат
./iclaude.sh --proxy-ca /path/to/ca.pem

# Отключить проверку TLS (небезопасно)
./iclaude.sh --proxy-insecure

# Запустить без прокси
./iclaude.sh --no-proxy

# Тест подключения
./iclaude.sh --test
```
