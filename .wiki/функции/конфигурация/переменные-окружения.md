# Переменные конфигурации iclaude

Все настройки iclaude хранятся в файле `.claude_config` в корне репозитория. Файл загружается автоматически при каждом запуске `./iclaude.sh`.

## Основные характеристики

### Расположение

```bash
cp .claude_config.example .claude_config
# Заполнить нужные значения
chmod 600 .claude_config   # устанавливается автоматически
```

`.claude_config` добавлен в `.gitignore` — содержит секреты, не коммитить. `.claude_config.example` — безопасный шаблон в git.

### Группы переменных

**Прокси:**

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `PROXY_URL` | не задан | URL прокси (`https://[CREDENTIALS]@host:port`) |
| `PROXY_CA` | не задан | Путь к CA-сертификату прокси |
| `PROXY_INSECURE` | `false` | Отключить проверку TLS (небезопасно) |
| `NODE_EXTRA_CA_CERTS` | из PROXY_CA | Алиас для PROXY_CA |

**Router (CCR):**

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CCR_PORT` | `3456` | Порт Claude Code Router |
| `DEEPSEEK_API_KEY` | не задан | API ключ DeepSeek |
| `OPENROUTER_API_KEY` | не задан | API ключ OpenRouter |

**PII Proxy:**

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `PII_PROXY_PORT` | `9000` | Порт PII Proxy |
| `PII_PROXY_MASKING_LEVEL` | `high` | Уровень маскирования |

**Autoresearch:**

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `AUTORESEARCH_DIR` | не задан | Путь к autoresearch-директории |
| `AUTORESEARCH_SKIP_PREPARE` | `false` | Не перезапускать prepare.py |
| `AUTORESEARCH_DAEMON_PORT` | `18640` | Порт HTTP status API (вариант B) |
| `AUTORESEARCH_POOL_SIZE` | `3` | Число параллельных агентов (вариант C) |

**Безопасность:**

| Переменная | По умолчанию | Описание |
|------------|-------------|----------|
| `CLAUDE_CODE_SKIP_PERMISSIONS` | не задан | Пропустить диалоги разрешений |

### Приоритет значений

CLI-флаги имеют приоритет над `.claude_config`. Например:
- `./iclaude.sh --proxy https://...` — переопределяет `PROXY_URL`
- `./iclaude.sh --no-proxy` — отключает прокси, даже если задан `PROXY_URL`

## Best Practices

- `PROXY_CA` вместо `PROXY_INSECURE=true` — безопаснее
- API ключи провайдеров хранить только в `.claude_config`, не в коде
- `chmod 600 .claude_config` — установить ограниченные права доступа
