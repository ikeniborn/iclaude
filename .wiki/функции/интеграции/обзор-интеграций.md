# Обзор интеграций iclaude

iclaude v4.0 включает 10 интеграций, 16 bash-модулей, 193+ функции и 71+ CLI-флагов. Каждая интеграция расширяет возможности Claude Code как AI-агента.

## Основные характеристики

### AI-возможности по интеграциям

| Интеграция | AI-возможность | Без интеграции | С интеграцией |
|------------|---------------|----------------|---------------|
| Chrome | Агент видит и управляет браузером | Только файлы/код | Web-автоматизация: навигация, клики, скрейпинг |
| Router | Выбор LLM-провайдера | Только Anthropic | DeepSeek/Gemini/Ollama/GPT-4 — по задаче |
| OAuth | Непрерывная сессия | Токен истекает через сутки | Автопродление — сессии ~1 год |
| LSP | Code intelligence | Синтаксическое дерево | Hover, go-to-definition, типы в контексте |
| Sandbox | Безопасное выполнение | Код запускается в окружении пользователя | Изолированная VM без побочных эффектов |
| Statusline | Видимость контекста | Расход токенов непрозрачен | Cache, стоимость, % контекста в реальном времени |
| Oh-My-Posh | Контекст окружения | Стандартный prompt | Git-ветка, окружение, модель в prompt |

### Критически важные для AI-работы

```
Proxy → OAuth → Chrome → Sandbox = полноценный AI-агент
```

- Без Proxy: Claude Code не работает в корпоративных сетях
- Без OAuth auto-refresh: сессия обрывается через сутки
- Без Chrome: агент не работает с браузером
- Без Sandbox: опасно запускать код от агента
