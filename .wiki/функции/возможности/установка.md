# Установка iclaude

Три варианта установки: изолированная (рекомендуется), системная и из lockfile. Изолированная установка размещает NVM, Node.js и Claude Code в `.nvm-isolated/` — без системных зависимостей и sudo.

## Основные характеристики

### Изолированная установка (рекомендуется)

```bash
# Первая установка
git clone https://github.com/ikeniborn/claude.git
cd claude
./iclaude.sh --isolated-install
# Создаёт: .nvm-isolated/ (~278MB), .nvm-isolated-lockfile.json
```

**Преимущества:** портабельность между машинами, нет конфликтов с системным Node.js, не требует sudo, воспроизводимые версии через lockfile.

### Установка после git clone

**Вариант 1 — полное окружение из git:**

```bash
git clone https://github.com/ikeniborn/claude.git && cd claude
./iclaude.sh --repair-isolated  # восстановить симлинки
./iclaude.sh                    # запуск
```

**Вариант 2 — из lockfile (легче для git):**

```bash
./iclaude.sh --install-from-lockfile  # точные версии из lockfile
```

### Ключевые команды установки

| Команда | Описание | Sudo |
|---------|----------|------|
| `--isolated-install` | Первая установка изолированного окружения | Нет |
| `--repair-isolated` | Починка симлинков после git clone | Нет |
| `--install-from-lockfile` | Установка точных версий из lockfile | Нет |
| `--install-lsp` | LSP серверы (TypeScript + Python) | Нет |
| `--install-pii-proxy` | PII Proxy (Python venv + Presidio NLP) | Нет |
| `--install-microvm` | Firecracker (~1.4GB) | Да |
| `--install-autoresearch` | Зависимости autoresearch (uv) | Нет |
| `--create-symlink` | Глобальный симлинк `iclaude` | Да |
| `--check-isolated` | Статус изолированного окружения | Нет |
| `--cleanup-isolated` | Удаление окружения (сохраняет lockfile) | Нет |

### Системная установка

```bash
./iclaude.sh --install   # системный npm (~200MB, требует sudo)
```

Не рекомендуется: конфликты с системным Node.js, требует sudo, не портабельна.

## Нативный бинарник (с v2.1.114)

Claude Code использует нативный бинарник `bin/claude.exe` (~237MB), который исключён из git (превышает 100MB лимит GitHub). После `git clone` требуется запустить `--repair-isolated` для загрузки бинарника через `npm install` + postinstall.

**Порядок определения бинарника:**
1. `$npm_prefix/bin/claude` (симлинк)
2. `bin/claude.exe` (нативный бинарник, v2.1.114+)
3. `cli.js` через `node` (legacy, до v2.1.114)
