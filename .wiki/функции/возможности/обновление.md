# Обновление Claude Code

Обновление Claude Code в изолированном окружении выполняется одной командой. После обновления lockfile обновляется автоматически.

## Обновление

```bash
# Обновить Claude Code до последней версии
./iclaude.sh --update

# После обновления автоматически:
# ✅ Claude Code обновляется до последней версии
# ✅ Lockfile обновляется с новой версией
# ✅ Симлинки и права доступа восстанавливаются
```

## Проверка после обновления

```bash
# Убедиться, что версия в lockfile совпадает с установленной
./iclaude.sh --check-isolated

# Вывод должен показывать совпадение:
# - Claude Code: X.X.X
# - claudeCodeVersion: "X.X.X" (в lockfile)
```

## Нативный бинарник

Начиная с версии 2.1.114 Claude Code использует нативный бинарник `bin/claude.exe` (~237MB). После обновления `--update` бинарник обновляется автоматически через `npm install` + postinstall.

**Порядок определения бинарника после обновления:**
1. `$npm_prefix/bin/claude` (симлинк)
2. `bin/claude.exe` (нативный бинарник, v2.1.114+)
3. `cli.js` через `node` (legacy fallback)

## Установка конкретных версий

```bash
# Установить точные версии из lockfile (воспроизводимая установка)
./iclaude.sh --install-from-lockfile

# Восстановить симлинки без переустановки
./iclaude.sh --repair-isolated
```
