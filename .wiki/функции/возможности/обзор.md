# Обзор возможностей iclaude

iclaude.sh — bash-обёртка для запуска Claude Code с прокси, изолированным окружением, OAuth auto-refresh, CCR, PII-прокси и microVM sandbox.

## Основные характеристики

### CLAUDE_CODE_* переменные

Специфические переменные самого Claude Code (отдельно от iclaude-переменных):

| Переменная | Назначение |
|-----------|------------|
| `CLAUDE_CODE_MAX_OUTPUT_TOKENS` | Лимит output токенов (решение "token maximum exceeded") |
| `CLAUDE_CODE_ENABLE_TASKS` | Tasks system (включить/отключить) |
| `CLAUDE_CODE_NO_CHROME` | Chrome integration (включить/отключить) |
| `CLAUDE_CODE_MODEL` | Выбор модели (opus/sonnet/haiku) |
| `CLAUDE_CODE_SESSION_TIMEOUT` | Таймаут сессии |
| `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS` | Agent Teams (экспериментально) |

### Решение "output token maximum exceeded"

```bash
# В .claude_config добавить:
CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000
```

Перезапустить `./iclaude.sh`.

### Agent Teams (экспериментально)

Координация нескольких экземпляров Claude Code как команды:

```bash
# В .claude_config:
CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
```

Внимание: значительно увеличивает использование токенов.
