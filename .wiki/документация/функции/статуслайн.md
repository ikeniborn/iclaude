# Статуслайн (Status Line)

Кастомный скрипт `claude-statusline.sh`, который отображает метрики Claude Code в строке состояния терминала в реальном времени. Получает JSON с данными сессии через STDIN от Claude Code. Требует Claude Code v2.1+.

## Основные характеристики

### Компоненты строки состояния (слева направо)

1. **Контекст (токены)**: совокупные токены (billing) + активный контекст (только новые токены, без кэша)
2. **Кэш**: `[cache]79K` — только при cache > 0
3. **Имя модели**: `display_name` из данных сессии
4. **Стоимость**: `total_cost_usd` в USD
5. **Прокси**: `[proxy]` если прокси настроен
6. **Router**: `[router]provider` если CCR активен
7. **Сессия**: 📄 — кликабельная OSC 8 ссылка на TOON-файл сессии
8. **Память**: 🧠 — OSC 8 ссылка на `MEMORY.md` проекта (только если файл существует)
9. **Git**: ветка + количество незафиксированных изменений
10. **PII proxy**: 🛡{count} — если активен `--pii-proxy`

### Три адаптивных режима (по ширине терминала)

| Режим | Ширина | Содержание |
|-------|--------|------------|
| Full | ≥130 col | Все компоненты |
| Compact | 110–129 col | Без router, proxy, git; сокращённое имя модели |
| Minimal | <110 col | Только токены, модель, стоимость |

### Многопровайдерная поддержка (v4.1+)

| Провайдер | Иконка | Расчёт стоимости |
|-----------|--------|-----------------|
| Anthropic (Claude) | (нет) | Из `total_cost_usd` |
| OpenAI/DeepSeek/OpenRouter | 🤖 | Расчётная (30+ моделей) |
| Ollama (локальные) | 🦙 | $0.00 (бесплатно) |
| Google Gemini | ✨ | Расчётная |
| Неизвестный | ❓ | $0.00 |

Автодетекция провайдера по структуре JSON (поля `context_window`, `usage`, `usageMetadata`).

### Session Link (📄) — оптимизации Phase 2.1+

Каждая сессия получает уникальный файл `.claude/sessions/readable-{session-id}.toon`. Операция append-only: только новые сообщения добавляются в файл (19x быстрее vs полная регенерация). Полная перестройка только при `/compact` или первом запуске.

### Задержка появления статуслайна

**Трёхфазный подход:** 0–30 сек — нет вывода (ожидание завершения системных сообщений Claude Code), после 30 сек + первое сообщение пользователя — статуслайн появляется. Устраняет race condition с асинхронными системными сообщениями.

## Расчёт активного контекста

```
TOTAL_CONTEXT = used_percentage × context_window_size  (включает кэш)
ACTIVE_TOKENS = TOTAL_CONTEXT - CACHE               (только новые токены)
```

После `/compact`: ACTIVE_TOKENS = ~652 (новые), CACHE = ~154K (сжатый контекст). Это чётко разделяет новую беседу и кэшированный контекст.

## Настройка

Добавить в `settings.json`:

```json
{
  "statusLine": {
    "type": "command",
    "command": "/absolute/path/to/.nvm-isolated/.claude-isolated/scripts/claude-statusline.sh"
  }
}
```

Debug-режим: `DEBUG_STATUSLINE=1` → `/tmp/claude-statusline-debug.log`
