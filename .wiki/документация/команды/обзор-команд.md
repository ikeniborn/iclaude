# Обзор команд iclaude.sh

Справочник CLI-команд iclaude.sh, сгруппированных по категориям. Все команды запускаются как `./iclaude.sh [флаг]`.

## Основные характеристики

### Ежедневное использование

| Команда | Описание |
|---------|----------|
| `./iclaude.sh` | Запуск с сохранёнными настройками |
| `./iclaude.sh --no-proxy` | Запуск без прокси |
| `./iclaude.sh --update` | Обновление Claude Code (npm + lockfile) |
| `./iclaude.sh --router` | Запуск через CCR (DeepSeek/Ollama) |
| `./iclaude.sh --pii-proxy` | Запуск с PII-маскированием |
| `./iclaude.sh --sandbox-microvm` | Запуск в Firecracker KVM |

### Изолированная среда

| Команда | Sudo | Описание |
|---------|:----:|----------|
| `--isolated-install` | Нет | Первая установка |
| `--repair-isolated` | Нет | После `git clone`: binary + symlinks |
| `--install-from-lockfile` | Нет | Установка из lockfile (воспроизводимо) |
| `--check-isolated` | Нет | Статус среды |
| `--create-symlink` | Да | Глобальный symlink `/usr/local/bin/iclaude` |
| `--cleanup-isolated` | Нет | Удаление среды (сохраняет lockfile) |
| `--repair-plugins` | Нет | Починка путей плагинов |

### Прокси

| Команда | Описание |
|---------|----------|
| `--proxy <url>` | Установить прокси |
| `--proxy-ca <file>` | CA сертификат для HTTPS прокси |
| `--proxy-insecure` | Отключить проверку TLS |
| `--test` | Тестировать подключение |
| `--no-proxy` | Запуск без прокси |
| `--clear` | Очистить сохранённые credentials |

### Расширенные функции

| Команда | Описание |
|---------|----------|
| `--install-router` | Установить CCR |
| `--check-router` | Статус Router |
| `--install-pii-proxy` | Установить PII proxy (venv + Presidio ~587MB) |
| `--install-microvm` | Установить Firecracker (~1.4GB) |
| `--check-microvm` | Проверить готовность microVM |
| `--install-lsp` | LSP-серверы (TypeScript + Python) |
| `--install-statusline` | Установить claude-statusline.sh |
| `--install-posh` | Oh My Posh темы |
| `--install-graphify` | Graphify knowledge graph |

### Тестирование

```bash
bash -n iclaude.sh                                    # Валидация синтаксиса
python3 -m pytest tests/test_patterns_examples.py -v  # Security hooks (28 тестов)
./iclaude.sh --test                                   # Тест прокси
./iclaude.sh --check-isolated                         # Статус среды
```

## Применение в контексте iclaude

После `git clone` обязательный шаг: `./iclaude.sh --repair-isolated`. Без него native binary (`bin/claude.exe`, ~237MB, не в git) не скачивается и Claude Code не запускается.

Chrome integration отключена по умолчанию (`--no-chrome`). Tasks system включена по умолчанию.
