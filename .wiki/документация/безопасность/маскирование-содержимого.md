# redact-secrets.py (маскирование содержимого инструментов)

PreToolUse хук второго слоя защиты. Вместо блокировки (как block-secrets.py) маскирует содержимое аргументов инструментов через механизм `toolInputOverride` (Claude Code v2.0.10+). Claude видит только маскированные данные, оригинал не передаётся.

## Основные характеристики

### Покрытые паттерны (v2, 2026-02-25)

| Категория | Паттерн | Плейсхолдер |
|-----------|---------|-------------|
| Anthropic/OpenAI/Stripe API ключи | `sk-ant-...`, `sk-proj-...`, `sk-or-v1-...` | `[API_KEY_REDACTED]` |
| AWS Access Key ID | `AKIA{16}` | `[AWS_ACCESS_KEY_ID]` |
| AWS Secret Access Key | `VAR_NAME={40}` (по имени переменной) | `VAR_NAME=[AWS_SECRET_KEY_REDACTED]` |
| PEM private keys | `BEGIN * PRIVATE KEY` | `[PRIVATE_KEY_REDACTED]` |
| GitHub PAT классический | `ghp_`, `gho_`, `ghu_`, `ghs_`, `ghr_` | `[GITHUB_TOKEN]` |
| GitHub fine-grained PAT | `github_pat_{82+}` | `[GITHUB_TOKEN]` |
| Credentials в URL | `scheme://user:pass@host` | `[CREDENTIALS]` |
| Пароли в конфигах | `password = value` | `[PASSWORD_REDACTED]` |
| Generic API ключ/токен | `api_key: "value"` в кавычках | `[SECRET_REDACTED]` |
| JWT | `eyJ...` (три части base64url) | `[JWT_REDACTED]` |
| .env переменные | `VAR_WITH_KEY_TOKEN=value{20+}` | `[REDACTED]` |

### Инструменты и поля для сканирования

Сканируются инструменты: `Write`, `Edit`, `MultiEdit`, `Bash`

Поля: `content`, `command`, `new_string` — но **не** `old_string`

### Механизм toolInputOverride

```python
# Хук печатает модифицированные аргументы в stdout:
print(json.dumps({
    "hookSpecificOutput": {
        "toolInputOverride": new_tool_input
    }
}))
```

Claude Code v2.0.10+ подхватывает этот вывод и выполняет инструмент с уже маскированными данными.

### Важные архитектурные решения

**`Edit.old_string` не маскируется** — это поисковый паттерн для поиска в файле. Маскирование нарушит поиск строки и сломает операцию Edit.

**Порядок паттернов**: специфичные (AWS, GitHub PAT) применяются перед общими (.env). Двойное перемаскирование предотвращается lookahead `(?!"?\[)`.

**Python 3.8+**: `from __future__ import annotations` для совместимости с Ubuntu 20.04 LTS.

## Известные ограничения

| Ограничение | Обходной путь |
|-------------|--------------|
| Нет Luhn-проверки номеров карт | Повышен риск false positive для числовых ID |
| Google AI (`AIzaSy...`), Stripe (`sk_live_`) не покрыты | Добавить паттерны вручную |
| Generic secret требует кавычки | YAML без кавычек не покрывается |
| Нет NLP — только regex | PII (имена, email) не маскируются автоматически |
