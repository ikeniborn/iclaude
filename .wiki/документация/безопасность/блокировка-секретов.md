# block-secrets.py (блокировка доступа к файлам с секретами)

PreToolUse хук первого слоя защиты в iclaude. Перехватывает каждый вызов инструментов Read/Edit/Write/Bash до передачи в Claude Code и блокирует доступ к файлам, содержащим секреты, по путям.

## Основные характеристики

### Защищённые паттерны путей

| Паттерн | Действие |
|---------|---------|
| `.env`, `.pem`, `.key`, `.p12`, `.pfx` | Блокируется (exit 2) |
| `.ssh/`, `.gnupg/` | Блокируется (exit 2) |
| `credentials`, `secret`, `.aws`, `.kube` | Блокируется (exit 2) |
| `token`, `id_rsa`, `id_ed25519`, `.netrc` | Блокируется (exit 2) |

### Исключения (разрешены)

| Паттерн | Причина |
|---------|---------|
| `.env.example`, `.env.sample`, `.env.template` | Шаблоны не содержат реальных данных |
| `.nvm-isolated/.claude-isolated/hooks/` | Само-исключение для хуков iclaude |

### Протокол ответа хука

| Действие | Exit code | stdout | Эффект |
|----------|:---------:|--------|--------|
| Разрешить | `0` | пусто | Инструмент выполняется |
| Блокировать | `2` | сообщение | Инструмент не выполняется |

### Fail-open принцип

При JSON-ошибке или `tool_input: null` хук выходит с кодом 0 (разрешить). Безопасность не жертвует доступностью.

## Связанные концепции

Работает в паре с [[redact-secrets|redact-secrets.py]] — второй слой, который маскирует содержимое аргументов инструментов (а не блокирует по пути).

`Edit.old_string` **не маскируется** — это поисковый паттерн для поиска в файле. Маскирование привело бы к ошибке "строка не найдена".

## Расположение и конфигурация

Путь: `.nvm-isolated/.claude-isolated/hooks/block-secrets.py`

Конфигурация в `settings.json` (хранится в `$CLAUDE_CONFIG_DIR`):

```json
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": ".*",
        "hooks": [
          {
            "type": "command",
            "command": "python3 .nvm-isolated/.claude-isolated/hooks/block-secrets.py"
          }
        ]
      }
    ]
  }
}
```

## Тестирование

```bash
# Должен вывести "BLOCKED" и выйти с кодом 2
echo '{"tool_name":"Read","tool_input":{"file_path":"/project/.env"}}' \
```
