# Телеметрия и мониторинг

OTel-стек реализован. Метрики и логи отправляются через OTLP/HTTP в `otel-collector` → Loki/Prometheus → Grafana.

## Конфигурация (`lib/telemetry/otel.sh`)

`setup_telemetry()` вызывается при старте iclaude. Устанавливает OTEL_* переменные и экспортирует их в окружение Claude Code.

### Переменные `.claude_config`

| Переменная | Default | Описание |
|---|---|---|
| `ICLAUDE_NO_TELEMETRY` | `0` | `1` — полный opt-out |
| `OTEL_EXPORTER_OTLP_ENDPOINT` | `http://127.0.0.1:4318` | OTLP HTTP endpoint |
| `OTEL_EXPORTER_OTLP_CREDENTIALS` | — | `user:password` — lib сам генерирует BasicAuth заголовок |
| `OTEL_LOG_USER_PROMPTS` | `1` | `0` — не логировать тело промптов |
| `PROXY_PROFILE` | `default` | Метка профиля в resource attrs |

### Два режима endpoint

**Локальный (та же машина):**
```bash
OTEL_EXPORTER_OTLP_ENDPOINT="http://127.0.0.1:4318"
# OTEL_EXPORTER_OTLP_CREDENTIALS не нужен
```

**Внешний (другая машина → otel.ikeniborn.ru):**
```bash
OTEL_EXPORTER_OTLP_ENDPOINT="https://otel.ikeniborn.ru"
OTEL_EXPORTER_OTLP_CREDENTIALS="otel:пароль"
# lib автоматически: base64("otel:пароль") → Authorization=Basic ...
```

### Логика генерации заголовка

Если `OTEL_EXPORTER_OTLP_CREDENTIALS` задан и `OTEL_EXPORTER_OTLP_HEADERS` не задан — `otel.sh` делает:
```bash
b64=$(printf '%s' "${OTEL_EXPORTER_OTLP_CREDENTIALS}" | base64 -w 0)
export OTEL_EXPORTER_OTLP_HEADERS="Authorization=Basic ${b64}"
```

## Публичный endpoint (otel.ikeniborn.ru)

Traefik проксирует `https://otel.ikeniborn.ru` → `http://otel-collector:4318` с BasicAuth.

- TLS: Let's Encrypt
- Auth: BasicAuth, пользователь `otel`
- Конфиг: `/opt/minipc-traefik/conf.d/otel.yml`
- Пароль: `/tmp/traefik-deploy-creds.txt` (только на minipc, chmod 600)

Работающие endpoints: `/v1/logs`, `/v1/metrics` → HTTP 200. Traces pipeline не настроен.

## Resource attributes

```
service.name=claude-code
service.namespace=iclaude
iclaude.project=<git repo name>
host=<hostname>
wrapper.version=<ICLAUDE_VERSION>
proxy.profile=<PROXY_PROFILE>
deployment.environment=production
```

## Opt-out

```bash
# В .claude_config:
ICLAUDE_NO_TELEMETRY=1
# Или при запуске:
iclaude --no-telemetry
```
