# Адаптеры провайдеров статуслайна

Система адаптеров в `claude-statusline.sh` обеспечивает унифицированное отображение метрик для разных LLM-провайдеров. Расположена в `.nvm-isolated/.claude-isolated/scripts/lib/`.

## Основные характеристики

### Файловая структура

```
scripts/lib/
├── provider-adapter.sh    — Factory & детекция провайдера
├── pricing-lookup.sh      — Расчёт стоимости (30+ моделей)
└── adapters/
    ├── anthropic.sh       — Claude API (native)
    ├── openai.sh          — OpenAI/DeepSeek/OpenRouter
    ├── ollama.sh          — Локальные модели
    ├── gemini.sh          — Google Gemini
    └── generic.sh         — Fallback
```

### Детекция провайдера

Автоматическая детекция по структуре JSON от Claude Code:

| JSON-поле | Провайдер |
|-----------|-----------|
| `context_window.total_input_tokens` | Anthropic (Claude) |
| `usage.prompt_tokens` + `model` начинается с `llama`/`qwen`/`mistral` | Ollama |
| `usage.prompt_tokens` + `completion_tokens` | OpenAI/DeepSeek/OpenRouter |
| `usageMetadata.promptTokenCount` | Google Gemini |

### Расчёт стоимости

**Anthropic**: `total_cost_usd` берётся из JSON напрямую (pre-calculated).

**Остальные**: `(input_tokens / 1M) × input_price + (output_tokens / 1M) × output_price`. База цен: 30+ моделей, обновлена февраль 2026.

**Ollama**: всегда `$0.00` (локальные модели бесплатны).

### Streaming Mode (Phase 2.2+)

Детектор стриминга автоматически распознаёт SSE-чанки и аккумулирует токены в реальном времени. Состояние сессии: `$CLAUDE_DIR/streaming-state/$SESSION_ID.state`. Очистка: состояния старше 1 часа удаляются автоматически.

Оверхед: <15ms на чанк (детекция + обновление state + парсинг).
