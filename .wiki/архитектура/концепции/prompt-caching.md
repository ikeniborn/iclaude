# Prompt Caching

Механизм кэширования контекста беседы в Claude Code. Значительно снижает стоимость длинных сессий за счёт хранения сжатого summary на сервере Anthropic.

## Основные характеристики

### Механизм работы

1. **Создание кэша** (при `/compact`): Claude Code сжимает беседу в summary, которое сохраняется в server-side кэш. Тарифицируется как обычный input: $3.00/1M токенов.
2. **Повторное использование**: При последующих запросах summary читается из кэша по тарифу $0.30/1M — **90% скидка**.
3. **Истечение кэша**: TTL (Time To Live) = 5 минут. После 5 минут простоя кэш удаляется.

### Тарификация (Sonnet 4.5)

| Тип токена | Цена за 1M | Описание |
|-----------|-----------|---------|
| Regular Input | $3.00 | Сообщения пользователя, системные промпты |
| Cache Write | $3.00 | Создание кэша (такая же цена как input) |
| Cache Read | $0.30 | Чтение кэша (**90% дешевле!**) |
| Output | $15.00 | Ответы Claude |

### Расчёт экономии (пример)

Сценарий: 150 сообщений, `/compact` на 100-м сообщении.

**Без кэша** (50 запросов × $0.33): $16.50
**С кэшем**: $0.62 (создание) + $2.50 (50 чтений) = **$3.12**
**Экономия**: $13.38 (**81% снижение стоимости**)

Break-even: ~3–4 запроса после создания кэша.

### Отображение в Status Line

| Компонент | Что показывает |
|-----------|---------------|
| `💳` (кумулятивные) | Все токены сессии, кэш-чтение по $0.30/1M |
| `📊` (активный контекст) | Текущее окно с учётом кэша; влияет на auto-compact |
| `📦` (кэш) | Объём кэша отдельно — видимость для оптимизации |

### Важные уточнения

- Кэш **участвует в биллинге** (входит в `total_input_tokens`), но по скидочному тарифу
- Кэш **является частью активного контекста** → влияет на `used_percentage` и триггер auto-compact
- `current_usage.cache_*` в API — данные только **текущего** запроса, не накопленные
- Управление кэшем **автоматическое** — ручного контроля нет

### Реализация в claude-statusline.sh

```bash
CACHE_READ=$(echo "$SESSION_DATA" | jq -r '.context_window.current_usage.cache_read_input_tokens // 0')
CACHE_CREATION=$(echo "$SESSION_DATA" | jq -r '.context_window.current_usage.cache_creation_input_tokens // 0')
TOTAL_CACHE=$((CACHE_READ + CACHE_CREATION))
```
