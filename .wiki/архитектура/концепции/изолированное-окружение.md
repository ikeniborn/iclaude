# Изолированное окружение

Концепция переносимой установки NVM + Node.js + Claude Code в директории `.nvm-isolated/`, не затрагивающей системное окружение пользователя.

## Основные характеристики

### Цель

Позволяет запускать Claude Code:
- Без изменения системного Node.js/NVM
- С фиксированными версиями через [[lockfile]]
- С изолированной конфигурацией (`CLAUDE_CONFIG_DIR`)
- На любой машине после `git clone` + `--repair-isolated`

### Изоляция конфигурации

`CLAUDE_CONFIG_DIR` экспортируется перед запуском Claude и указывает на `.nvm-isolated/.claude-isolated/`. Это означает:
- Hooks, settings, skills — хранятся локально в репозитории
- Конфигурация не смешивается с `~/.claude/`
- Можно версионировать настройки через git

### Механизмы изоляции в iclaude

| Механизм | Статус | Описание |
|----------|--------|---------|
| `CLAUDE_CONFIG_DIR` | Всегда активен | Изоляция конфигурации |
| microVM (Firecracker) | Opt-in (`--sandbox-microvm`) | Изоляция на уровне ядра |
| bubblewrap (bwrap) | Удалён (2026-03) | Создавал 0-байт stub-файлы в других проектах |
