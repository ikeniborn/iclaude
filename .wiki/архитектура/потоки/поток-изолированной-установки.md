# Поток изолированной установки

Последовательность операций при установке изолированного окружения NVM + Node.js + Claude Code в директорию `.nvm-isolated/`.

## Основные характеристики

**Команда:** `./iclaude.sh --isolated-install`
**Диаграмма:** `docs/architecture/diagrams/data-flow-isolated-installation.md`

### Создаваемые артефакты

| Путь | Описание |
|------|---------|
| `.nvm-isolated/` | Корень изолированного окружения |
| `.nvm-isolated/nvm.sh` | Скрипт NVM |
| `.nvm-isolated/versions/node/v18.x.x/` | Node.js |
| `.nvm-isolated/npm-global/bin/claude` | Симлинк на CLI |
| `.nvm-isolated/.claude-isolated/` | Изолированная конфигурация |
| `.nvm-isolated-lockfile.json` | Файл зафиксированных версий |

### Этапы (17 шагов)

1. Создание директории `.nvm-isolated/`
2. Скачивание NVM `install.sh` с GitHub
3. Установка NVM, настройка `NVM_DIR`
4. `nvm install 18.20.8` в `.nvm-isolated/`
5. `npm install -g @anthropic-ai/claude-code`
6. Создание симлинка `npm-global/bin/claude`
7. Детектирование версий (`node --version`, `claude --version`)
8. Запись `.nvm-isolated-lockfile.json`

### Формат lockfile

```json
{
  "nodeVersion": "18.20.8",
  "claudeCodeVersion": "2.1.7",
  "installedAt": "2026-01-14T10:39:51Z",
  "nvmVersion": "0.39.7"
}
```

### После git clone

Нативный бинарник `bin/claude.exe` (~237MB) исключён из git. Для восстановления симлинков и загрузки бинарника:

```bash
./iclaude.sh --repair-isolated
```

Порядок детектирования пути claude: `$npm_prefix/bin/claude` → `bin/claude.exe` → `cli.js` (legacy).
