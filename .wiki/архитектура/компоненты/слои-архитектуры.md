# Слои архитектуры iclaude

iclaude организован в пять слоёв с чётким разделением ответственности. Каждый слой реализован как набор bash-модулей в директории `lib/`.

## Основные характеристики

| Слой | Цвет (диаграмма) | Ответственность |
|------|-----------------|-----------------|
| CLI Layer | синий | Точка входа, парсинг аргументов, отображение help |
| Core Layer | оранжевый | Proxy, OAuth, Router, Environment, Version Management |
| Installation Layer | зелёный | NVM, Node.js, Claude Code, Router — установка и обновление |
| Sandbox Layer | фиолетовый | microVM (Firecracker) lifecycle, KVM detection, virtiofsd |
| Infrastructure | красный | File I/O, git proxy config, credential storage, dependency check |

### CLI Layer

Единственная точка входа — `iclaude.sh`. Содержит два компонента:
- `cli-main` (`iclaude.sh:3561-3796`) — парсинг аргументов, маршрутизация к обработчикам
- `cli-usage` (`iclaude.sh:3344-3560`) — вывод справки

### Core Layer

Основная бизнес-логика. Шесть подмодулей:
- [[proxy-management]] — валидация URL, хранение credentials, тестирование соединения
- [[isolated-environment]] — управление `.nvm-isolated/`
- `version-management` — lockfile (save/install)
- `config-management` — изоляция `CLAUDE_CONFIG_DIR`
- [[oauth-token-management]] — автообновление токена за 7 дней до истечения
- [[router-management]] — интеграция с `ccr` (Claude Code Router)

### Installation Layer

Компоненты, вызываемые при установке:
- `nvm-installer`, `nodejs-installer`, `claude-installer`, `router-installer`
- `claude-updater` — обновление с очисткой временных папок `.claude-code-*`
- `symlink-manager` — симлинки `claude`, `ccr`, `npm`, `npx`
- `claude-path-finder` — поиск бинарника (3 варианта: симлинк → `bin/claude.exe` → `cli.js`)

### Sandbox Layer

Реализован в `lib/sandbox/`:
- `detect.sh` — определение KVM, платформы, дистрибутива
- `install.sh` — установка Firecracker, rootfs, nvm.img, TAP-сеть
- `microvm.sh` — [[microvm-launcher|жизненный цикл VM (v2)]]
- `status.sh` — статус microVM компонентов

### Infrastructure Layer

Вспомогательные утилиты:
- `credential-storage` — хранение proxy credentials (chmod 600)
- `git-proxy-config` — настройка git proxy с backup/restore
- `jq-validator` — проверка наличия jq
- `dependency-checker` — проверка curl, git, jq
- `output-formatters` — `print_info`, `print_success`, `print_warning`, `print_error`

## Порядок загрузки

```
Phase 0: core/init.sh
Phase 2–8.1: feature modules
Phase 14: command dispatch
```

Переменные, установленные `lib/core/init.sh` + `lib/nvm/setup.sh`:
- `ISOLATED_NVM_DIR` — `.nvm-isolated/`
- `CLAUDE_CONFIG_DIR` — экспортируется перед запуском Claude
- `NPM_CONFIG_PREFIX` — `$ISOLATED_NVM_DIR/npm-global`
