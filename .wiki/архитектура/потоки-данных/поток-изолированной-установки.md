# Поток изолированной установки

Последовательность операций при первичной установке изолированного окружения (`--isolated-install`): NVM → Node.js → Claude Code → симлинки → lockfile.

## Основные характеристики

**ID потока:** `isolated-installation-flow`

**Шаги:**

| Шаг | Компонент | Действие |
|-----|-----------|---------|
| 1 | `cli-main` | Приём команды `--isolated-install` |
| 2 | `isolated-environment` | Создание директории `.nvm-isolated/` |
| 3 | `nvm-installer` | Загрузка и установка NVM |
| 4 | `nodejs-installer` | Установка Node.js через `nvm install` |
| 5 | `claude-installer` | `npm install -g @anthropic-ai/claude-code` |
| 6 | `symlink-manager` | Создание симлинков: npm, npx, claude, ccr |
| 7 | `save-lockfile` | Определение и сохранение версий в lockfile |
| 8 | `cli-main` | Вывод сообщения об успехе |

## Артефакты

| Путь | Описание |
|------|----------|
| `.nvm-isolated/nvm.sh` | Скрипт NVM |
| `.nvm-isolated/versions/node/vX.X.X/` | Node.js |
| `.nvm-isolated/npm-global/bin/claude` | Симлинк или нативный бинарник |
| `.nvm-isolated-lockfile.json` | Зафиксированные версии |

**Пример lockfile:**
```json
{
  "nvmVersion": "0.39.7",
  "nodeVersion": "20.20.2",
  "claudeCodeVersion": "2.1.114",
  "installedAt": "2026-05-05T10:00:00Z"
}
```

## После git clone

Симлинки и нативный бинарник (~237 МБ) не хранятся в git. После клонирования необходимо:
```bash
./iclaude.sh --repair-isolated
```
