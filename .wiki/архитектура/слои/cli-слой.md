# CLI-слой (Command Line Interface)

Верхний слой архитектуры iclaude, отвечающий за взаимодействие с пользователем: разбор аргументов командной строки, отображение справки и координацию выполнения команд.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Файл | `iclaude.sh` |
| Диапазон строк | 3344–3796 |
| Тип | Script |

**Ответственности:**
- Разбор аргументов командной строки (`--proxy`, `--router`, `--sandbox-microvm` и др.)
- Отображение справочной информации (`--help`)
- Координация вызовов модулей Core-слоя
- Вывод форматированных сообщений пользователю

**Компоненты слоя:**

| Компонент | Строки | Назначение |
|-----------|--------|-----------|
| `cli-main` | 3561–3796 | Главная функция: парсинг аргументов и роутинг команд |
| `cli-usage` | 3344–3560 | Отображение справки с примерами |

## Зависимости

CLI-слой является точкой входа и вызывает:
- [[proxy-management]] — обработка прокси-команд
- [[isolated-environment]] — управление изолированным окружением
- Version Management — управление версиями и lockfile
- OAuth Token Management (опционально) — проверка токена перед запуском
- Router Management (опционально) — запуск через Router
